One thing to note
⚠️ Right now the game can't automatically verify that someone paid Stripe before showing levels 8–10. The pay button opens Stripe in a new tab — when they come back to the game they still see the paywall. To auto-unlock, you'd need a Stripe success redirect URL that calls window.unlockPaidLevels() — or just add a simple "I've paid" button for now that trusts the honour system, since the game itself is low stakes at £3.
